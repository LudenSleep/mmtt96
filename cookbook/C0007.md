# C0007 — Native Windows /x switches from Git bash/make: MSYS path rewrite
tags: windows,msys,make,assembler,gotcha · date: 2026-10-12 · phase/task: 1.3/T1 · origin: T1 summary gotchas

# Native Windows exes with `/x` switches from Git bash or make

- MSYS (Git bash, ezwinports make via sh) rewrites an argument starting with `/x` to a Windows path (`/p` -> `C:/Program Files/Git/p`).
- Symptom: the tool reports a bad/unknown file or switch, rc=1, no output (clownassembler `/p` failed this way).
- Fix: write `//x` (MSYS strips one slash), or export `MSYS_NO_PATHCONV=1` for the call.
- In a Makefile: `$(ASM) //p main.asm,../build/out.bin` (see `Makefile`, phase 1.3 T2).
- Tools with no usage text (clownassembler prints none; `/?` = "Unrecognised switch"): pin the version by sha256, not `--version`.
