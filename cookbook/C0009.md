# Probe an assembler's encoding choices with per-case size asserts

When: choosing or pinning an assembler for a byte-matching build; before trusting defaults for branch sizing, quick forms, absolute short/long, PC-relative.

How:
- Wrap each case in a start and end label inside a macro; assert `(end - start)` equals the expected byte size for that case (the assembler's own conditional + fatal message; a failed assert must exit non-zero and write no output).
- Keep one body file of all cases; run it under one thin wrapper per switch/option set, so each switch is measured on identical input.
- Plant one deliberately wrong expected size first: it must fail, proving the asserts are armed.
- Record per class: default encoding, forcing suffix/mnemonic, which switches change it, unsupported syntax.

Origin: phase 1.4 T1 (64 armed asserts, 17 switch wrappers; clownassembler v1.1.3).
