# Capstone m68k: zero-displacement indexed mode reported as base-displacement

Problem: Capstone 5.0.9 (M68K_000) reports the brief-extension indexed mode (d8,An,Xn) with d8 = 0 as
`AREGI_INDEX_BASE_DISP` instead of `INDEX_8_BIT`. A form classifier keyed on the address-mode enum then invents a
68020 full-extension form that the 68000 cannot encode.

Technique:
- On a 68000 target, treat both enum values as the brief-extension form (one mapped form, e.g. `d8anxn`).
- Cross-check: the instruction length must match a one-word extension.

Origin: phase 1.6/T5 (433 sites in the verified code regions).
