# BizHawk (2.11, GPGX) Lua as a second Mega Drive oracle: traps

1. `client.reboot_core()` keeps the Lua script but drops memory callbacks registered before it: reset first, then register `event.onmemoryexecute*`.
2. The Lua starts after frame 1, so callbacks registered at script start miss boot; reboot then register.
3. GPGX asks for the optional Mega-CD BIOS on every cart load and after `reboot_core`; EmuHawk shows a modal "Warning" box that blocks the Lua. Close exactly that box from the driver (WM_CLOSE); any other dialog times the run out.
4. Near-headless: `client.speedmode(6400)` + `client.invisibleemulation(true)`, end with `client.exit()`.
Source: phase 1.2 T5 (`scripts/oracle/bizhawk.py`).
