# Prove a source-include hook is live: grep the wrapper, not only the hash

When: a build includes optional per-region source files (instruction form) in place of data, and the gate is a whole-image hash.

Why: an included-but-unused file, or a hook that silently falls back to data, still hashes OK; the hash alone does not prove the source path ran.

How:
- After the build, grep the generated wrapper for the include line of each source file, and have the splitter print a count (`split: src <n> regions` here).
- Pair with a negative control: perturb one operand in the source; the build must fail (end-of-region assert or hash), then restore.
