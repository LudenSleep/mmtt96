# Per-frame RAM sampling lands mid game-frame

- A recorder sampling at the video frame boundary can catch the game loop mid-update: half-applied steps, targets
  before offsetting, a value one frame late then two updates at once. Count such frames separately; judge divergence by
  persistent differences, not a single-frame offset.
- A flag computed before the view update uses the previous frame's view: measure margins against that frame.
- Pokes from a frame-done hook land mid game-frame. For exact input/output of a routine, install write taps on the words
  it fills (they fire with live values) and key the analysis on what the tap saw.
- A routine working on a scratch copy of a slot overwrites pokes of the slot being processed: poke a slot that is not
  moving, or hold the poke for several frames.

Evidence: phase 1.9 T5 (28), T9 (37), T6 (34), T8 (31, 33).
