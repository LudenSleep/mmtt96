# Proving a build-time boundary assert actually fires

- Probe the assert/fail directive in the TAKEN branch: assemblers skip untaken `if` bodies, so an unknown directive there passes silently; an unknown directive in a taken branch "fails" with a syntax error, which is not a real assert. In clownassembler `fail`/`error` are not directives; use `if * <> $END` / `inform 3,"msg"` / `endc` (rc=1, no output written).
- In a ROM-derived split, a regions-table edit (row end moved) is refused first by the manifest/splitter (overlap or gap, exit 2), and a consistent shift builds OK because bytes come from the ROM. To test the assembler end assert, make one generated region file short by 2 bytes and assemble: `init: end mismatch`, exit 2.
