# MAME debugger breakpoint indices are hexadecimal

Problem: `bpset` returns an index printed in hex; `bpdisable 10` disables breakpoint 0x10, not the tenth. A probe
script that formats indices in decimal silently disables the wrong breakpoint and reports a false "never hit".

Technique:
- Format every breakpoint/watchpoint index with `%X` before `bpdisable`/`bpclear`/`bpenable`.
- After disabling, list breakpoints (`bplist`) once and assert the intended one is disabled.

Origin: phase 1.6/T1 (breakpoint probes over new code rows; MAME 0.289).
