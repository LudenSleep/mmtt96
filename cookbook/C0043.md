# Ghidra: a label at a DEFAULT function entry renames the function

A global label symbol created at the entry of a DEFAULT (auto-named) function renames the function
(`SymbolManager.createCodeSymbol` -> `tryUpdatingDefaultFunction`); labels applied before auto-analysis also make
Ghidra create functions after them. Apply labels in a post-analysis script, or create the label in the function
namespace and then `setNamespace(global)`.

Evidence: phase 1.9 T34 (13, 23), `scripts/ghidra/Mmtt96Apply.java` labels pass.
