# Pick the assembler by a full-region scan: converter defect vs assembler rewrite

When: a disassembly-to-source converter feeds a matching build and an assembler candidate mismatches on some regions.

How:
- Run the converter's self-check (assemble each region alone, compare with the ROM) over every verified code region, not a sample.
- Classify each mismatch: converter defect (wrong operand spelling, missing size suffix, unsupported addressing mode in the emitter) vs assembler rewrite (the assembler changes an explicit encoding regardless of spelling).
- Fix converter defects first; only assembler rewrites that no spelling or switch avoids justify changing assembler.

Origin: phase 1.4 T3 (194/194 regions; clownassembler rewrote literal-source CMP/ADD/SUB/AND/OR to the immediate form, R1.4-002; switched to Macroassembler AS).
