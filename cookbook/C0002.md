# Locating Amiga-packed blobs in a Mega Drive ROM

Some MD games ship assets packed with Amiga tools (e.g. Imploder, magic `IMP!`).

1. Scan the ROM for the packer magic.
2. Bound each blob from its own header (Imploder: size = endOffset + 0x32 = 12 B header + data + 0x2E trailer + 4 B checksum).
3. Confirm each bound with the packer's own checksum (Imploder: BE16 word sum, seed 7) before trusting it.
4. Cross-check: confirmed blobs should tile the data area exactly; gaps are leftovers (e.g. HUNK_END) to label, not ignore.
Source: phase 1.1 T2, report R1.1-003.
