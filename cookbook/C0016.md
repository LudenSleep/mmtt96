tags: make,build,negative-control,gotcha · date: 2026-10-13 · phase/task: 1.6/T3 · origin: T3 summary gotchas

# make can skip a rebuild when a dependency changes in the same second as the target

Problem: on this host's file timestamps, editing a dependency within the same second the target was written can
leave the target looking up to date; a negative control (planted fault) then "passes" against the stale binary.

Technique:
- Before a negative control, delete the target (e.g. `build/mmtt96.bin`) so make must rebuild.
- Prefer `make clean && make build` for any decisive comparison.

Origin: phase 1.6/T3 (names-layer negative controls).
