# MAME runs: per-run EEPROM, save-state time, EEPROM layout by diff

- MAME writes cartridge EEPROM to `nvram/` under the cwd at exit; later runs inherit those saves. Give every run its
  own `-nvram_directory` copied from a seed (here `.run/mame/nvram_seed`).
- A save state restores machine time: `-seconds_to_run` counts from the restored time, so a loaded run ends early
  unless the limit is raised (`mame.py --secs 900`). Long power-on scenarios (> ~19 s emulated) need it too.
- An EEPROM layout falls out of one save: diff the per-run nvram image against a boot run's; the changed span's start
  and length give the slot offset and size.

Evidence: phase 1.9 T1 (gotchas 26-27), T10 (39, 42).
