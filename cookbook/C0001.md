# Name probe scripts uniquely: never shadow a stdlib module

A scratch script named `dis.py` in the working directory shadows stdlib `dis`. capstone imports `inspect`, which imports `dis`, so the import resolves to the scratch file and fails with a circular-import error.

- Name probes with a project prefix (`probe_dis68k.py`), never a stdlib module name (`dis`, `code`, `token`, `inspect`, `types`, `struct`).
- Run untrusted or probe Python with `-I` so the script directory is not on `sys.path` first.
