# Cheap measurement from recorded RAM series

- Read a probe pair's base/variant whole-RAM dumps (64 KiB per frame) directly for a per-frame series; a divergence
  summary that lists only first frame and count is not enough for measured quantities.
- Check a movement model read from code by single-frame prediction: previous frame's words in, next frame's words out;
  skip frames with no or double movement (mid-frame sampling).
