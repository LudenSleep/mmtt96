# Proving an exception handler the hardware never raises (MAME frame injection)

When a vector target never runs in normal play, coverage cannot verify it. Inject the exception instead:
- in MAME, stop at a known PC, hand-build the 68000 exception frame (SR + return PC pushed, SP adjusted), set PC to the
  vector target;
- breakpoint on the handler entry (entered) and a return breakpoint at the interrupted PC that compares SP with its
  pre-injection value (returned cleanly);
- positive control: a vector whose handler is already verified, same procedure, must enter and return;
- negative control: a vector pointing at fill / padding must not behave like a handler.

Counts per vector (entered/returned with exact SP) are the evidence for promoting the row. Source: 1.7/T5 (code_01FA2E).
