# Struct field at offset +0 renders as the bare base name

Problem: the listing's name substitution matches a struct field only when the address is strictly past the base
(`addr < a`), so the +0 field never appears and its use count reads 0, which looks like a dead field.

Technique:
- Expect +0 fields to show 0 uses; check their use via the base name's count instead.
- Do not delete or rename a +0 field on a zero count alone.

Origin: phase 1.6/T4 (slot and pairrec structs).
