# Probe design: controls and discriminating pokes

- A diff probe needs a positive control (a poke that must diverge) besides the identical pair, or a broken diff passes.
- A "never written" negative control must also be checked on a boot run (this game writes ROM 000000 once at boot).
- Bounding-box midpoint vs mean: with two objects they coincide; place one of three or more objects asymmetrically by poke.
- "Relative to the view" vs "distance between two objects" when the view tracks their midpoint: drop one object from
  the view set by poke; the hypotheses then predict different outcomes.
