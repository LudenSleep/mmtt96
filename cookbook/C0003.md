# Resolving an ambiguous compression spec by variant grid

When a format description leaves choices open (bit order, table layout, end handling), do not pick one by reading.

1. Enumerate the variant grid (every combination of the open choices).
2. Decode every sample with every variant.
3. Accept only a variant that decodes all samples cleanly: exact output length fill, checksum match, and full input consumption.
4. A correct variant is all-or-nothing; wrong ones plateau well below 100%. Require a unique winner.
5. Keep the strict checks in the shipped decoder (no tolerance), so drift fails loudly.
Source: phase 1.1 T3 (IMP! decoder, 368/368 blobs).
