# Writing comments that the checkers read

- commentcheck misreads a plate line that starts with an identifier right after a line break: start it with a word.
- commentcheck RANGE form is `ram_<hex>-ram_<hex>` only; a renamed range start is written `<name> (<n> bytes)`.
- The names/no-names pair compared eol comment text de-named until T39; symbol names inside eol comments of sampled
  regions made it disagree. Since T39 eol text is compared raw.
- Mechanics claims: `confirmed` needs >= 3 distinct run ids in the bracket or one controlled probe; a census probe id
  adds no run ids (list its runs); run ids resolve only from tracked `config/oracle/*.tsv` and split on `+`.

Evidence: phase 1.9 T12 (52), T40.1 (50), T16 (26), T39, T43 (20), T44 (19), T9 (44), T7 (36), T8 (37).
