# Signature propagate and region-id names

- `signatures.py propagate` refuses a name when the anchor's signature group already holds a named routine (identical
  short bodies): split the group first, or name both members on one sighash (`propagate --member`, T42).
- It refuses an address already in the registry (rename = delete the neutral row, then propagate); `--dry-run` is not
  side-effect free.
- A routine name equal to a region-id label changes the emitted source and breaks srcform hashes (see C0024): describe
  such entries with plate comments. A region id rename needs a second `make build` (stale wildcard).

Evidence: phase 1.9 T22 (25), T20 (22), T24 (20, 21), T34 (24), T42.
