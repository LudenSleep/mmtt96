# MAME debugger breakpoints from a Lua hook: census or alter a load

Driven from a scenario hook, debugger breakpoints at a decompressor entry/exit can log (source, dest, return) per frame
for a load census, or rewrite the source register at entry to swap one blob for another: a clean controlled probe of
what a blob holds. Pass a breakpoint condition as its own argument; count only output lines exactly equal to the hit
marker (the echoed command line contains it too, so a substring count reports a hit that never happened).

Evidence: phase 1.9 T10 (36), T43 (19).
