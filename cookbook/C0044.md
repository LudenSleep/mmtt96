# Assigning code to systems by call graph

Callee votes from big hub routines drag shared screen/text utilities into the hub's system. Count callee votes only
when all of a routine's few callers share one system, and let identity evidence (hardware ports, mode words, region
names) decide before proximity.

Evidence: phase 1.9 T11 (45), `scripts/census/systems.py`.
