# A write census shows that a field is written, never what it means

Problem: an oracle write census (address, size, writer PC, counts) proves a RAM field is live and who writes it,
but naming it by meaning (index, speed, flag) from that alone is guessing.

Technique:
- From a write census, name fields only neutrally by offset (e.g. `w00`, `f12`).
- A meaning name needs value datapoints: log written values across scenarios and show the semantics.
- Record the placeholder as honest, with the value census as the named upgrade path.

Origin: phase 1.6/T4 (struct fields renamed from idx_a/idx_b to w00/w02).
