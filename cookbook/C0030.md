# Scratch path aliases on Windows: subst breaks relpath, junctions bite rm -rf

## subst
A `subst` drive breaks Python code that mixes `Path.resolve()` (resolves to the real drive) with `os.path.abspath`
(keeps the subst drive): `os.path.relpath` then raises on the drive mismatch. Use a directory junction
(`cmd //c mklink /J <link> <target>`) instead; both spellings stay on one drive.

## Junction removal
`rm -rf` on a junction, or on a clone reached through one, follows into the target and deletes the real files.
Remove the link itself with `cmd //c rmdir <link>` (no `/s`), or move it aside.
