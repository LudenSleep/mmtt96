# `python -I` hides user site-packages

`python -I` (isolated mode) implies `-s`: the user site-packages directory is not on `sys.path`. A prerequisite
check for a package installed with `pip install --user` (for example capstone) reports it missing under `-I`.
Run that one check without `-I` (keep `-I` for code that reads untrusted downloads), or check the same interpreter
the build uses, without `-I`.

Evidence: phase 1.8 T3, `scripts/bootstrap.sh` capstone check.
