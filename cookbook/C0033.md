# Scripted menu input and save states in a MAME scenario driver

- Presses landing during a screen transition are dropped: space inputs >= 50 frames after a screen appears and confirm
  with a snapshot before the next step.
- A poked menu index byte can be ignored until a cursor press: poke index-1 and press Right (this game's course select).
- A driver that replays scripted inputs and saves a state at frame N overwrites that state when re-run from it for more
  than N frames. Idle or poked runs from a state use an input-free (unlisted) scenario id.

Evidence: phase 1.9 T1 (28), T5 (30), T6 (32).
