# Readability closeness is mechanical: sweep it by script before any manual wave

Symptom: a manual wave spends most of its effort on placeholder names; about 90% of wave 1's 110 name rows were
mechanical (fn_<addr6>, ram_FFxxxx, dat_/lbl_, propagated stub groups) at about one expert context per region.

Cause: closeness = nameable raw addresses + unnamed entries + embedded data runs; every term has a mechanical neutral
answer that needs no judgment.

Fix: one script pass per layer (RAM operands, I/O, ROM labels, routine entries through the signature registry, stub
group fan-out), each layer behind the byte gate (`make build`) and the names/signatures pairs; manual waves then carry
only comments and meaning names, batched by call graph (~1500 insns per coder run). Route: mechanical = unattended,
meaning = developer review (G62).
