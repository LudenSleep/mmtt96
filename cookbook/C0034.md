# MAME Lua: sharing globals with a helper script; wrapping an existing probe

- `dofile` runs in the global env, not the autoboot script's env: hooks it defines are invisible. Load helpers with
  `loadfile(path, "t", _ENV)()`.
- To get per-write values out of an existing drive script without editing it: loadfile it into a proxy `_ENV` whose
  `__newindex` wraps the hook globals (here `DRIVE_HOOK`/`DRIVE_DONE`) and add write taps logging frame, addr, pc, value.
- `install_read_tap` refuses an odd start address; round down to even. Guard tap bodies with `pcall`: an error inside a
  tap (for example reading a missing `cpu.state` key) fails silently and drops data.

Evidence: phase 1.9 T2 (34), T38 (20), T10 (41), T32 (21).
