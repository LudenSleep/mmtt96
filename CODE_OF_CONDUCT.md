# Code of conduct

Be respectful. Discuss the work, not the person; assume good faith; keep criticism specific and constructive.
Harassment, insults, personal attacks and discriminatory language are not acceptable in issues, pull requests,
discussions or any other project space.

The maintainers enforce this: they may edit or remove content and restrict participation that breaks it.

To report a problem, use GitHub's "Report content" feature on the comment, issue or pull request concerned.
