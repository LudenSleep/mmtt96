## Answer (returned verbatim, <=40 lines)
- Entry: reset PC = 0 and SSP = ASCII "DNLD". Word at 0x000000 is an illegal opcode, so the CPU traps through the illegal-instruction vector (offset 0x10) to 0x000200. Most other vectors also point to 0x000200. 0x000200 is the standard Sega init routine (ICD_BLK4 shape): its data table is at 0x00028E and it continues at 0x0002FA. Effective entry = 0x000200 (inferred from the vectors; not run in an emulator).
- Z80 boot stub: the standard 38-byte Sega init stub at 0x0002C4–0x0002EA, copied by the init loop at 0x00024E (count `#$25`, destination from table long 0x000294 = 0xA00000).
- Z80 sound driver: raw (uncompressed), 0x01597A–0x016DE6 (5228 B). Upload routine at 0x015918: Z80 reset 0xA11200 at 0x015918, dest `lea 0xA00000` at 0x015928, source `lea 0x01597A` at 0x01592E, count `move.w #$146B` + dbra at 0x015934/0x01593A (0x146C bytes). First byte 0xF3 (DI); the end abuts the 68k bus-request routine at 0x016DE6. Credited to Tim Bartlett (R1.1-001). No other 0xA00000 copy loop: the other abs-long hits at 0x05686E and 0x0E40A0 are inside compressed blobs.
- Compression: Amiga Imploder format, magic "IMP!". Decruncher entry 0x035416 (19 `jsr` call sites), in-place core 0x03544A. 368 blobs tile 0x0477BA–0x0FFB1A with no gaps. Every blob start is referenced as an absolute long in 0x000000–0x0477BA (368/368).
- Padding: 0x00 fill at 0x01FACC–0x020000 (0x01FACC is also the bus-error vector target), and at 0x0FFB20–0x0FFFFD. The last 3 bytes are not fill.

## Findings
Format spec (prose, from the decruncher at 0x035416 / 0x03544A):
- Header 12 B: magic "IMP!" (4); unpacked length (BE long, +4); end offset (BE long, +8), measured from the blob start.
- Trailer at blob+endOffset: 3 longs that restore the first 12 output bytes (the header area); a BE long literal-run count (bytes copied verbatim, backwards, first); a BE word initial bit buffer (if it is non-negative, the source pointer steps back one byte); then a 28-byte table of 7 longs (match length-class and offset-width parameters, read into a stack frame).
- Total blob size = endOffset + 0x32. Evidence: (a) the wrapper copies `(endOffset+0x32)>>2` longs into the destination before decoding in place; (b) with +0x32 all 368 blobs tile contiguously (every inter-blob gap is 0; with +0x2E every gap is exactly 4); (c) the last 4 bytes are the Imploder checksum, 7 + the sum of BE16 words over bytes 0..endOffset+0x2D, mod 2^32 (R1.1-003): it matches on 368/368 blobs (`.run/probe/p8.py`). The game's decruncher does not check it.
- Decoding runs backwards: the output end is dest+unpackedLength, and source reading goes down from the trailer. Flag bits are shifted out of a byte buffer, refilled from the source with `addx` (the end-marker-bit idiom). The match length class (1..4, or extended by a byte or 3 bits plus 5) selects the table entries for offset bit widths. Done when the output pointer reaches dest. Result is ok if the source pointer lands exactly on dest (rc -1 / Z clear).
- Unpacked sizes are 576–27840 B; total unpacked 2,132,394 B from 753,056 B packed (sum of endOffset+0x2E; +4×368 for the +0x32 sizes).
- One decoded layout seen at the image loaders 0x01398E–0x013B70: word tile count, word width, word height, 16 palette words, w×h tilemap words, then tiles. DMA via 0x01FA50. Applies to that caller family only.
