Findings:
- Entry: reset PC 0 and SSP "DNLD". Word 0 is an illegal opcode, which traps via vector 0x10 to 0x000200 (standard Sega init). Effective entry is 0x000200 (inferred; confirm in phase 1.2).
- Z80 driver: raw, uncompressed, 0x01597A-0x016DE6 (5228 B), uploaded by the routine at 0x015918. It is the only 0xA00000 copy loop besides the boot stub (0x0002C4-0x0002EA, copied at 0x00024E). Driver credit: Tim Bartlett (R1.1-001).
- Decruncher: wrapper 0x035416 (copies the blob to dest, decodes in place), core 0x03544A. 19 jsr call sites. All 368 blob starts are referenced as abs longs below 0x0477BA.
- Unpacked sizes are 576-27840 B, total 2,132,394 B. One caller family (0x01398E-0x013B70) decodes an image layout: tile count, width, height, 16 palette words, tilemap, tiles.
- Still unknown: 0x020000-0x0477BA mixes code (0x035416, 0x03F29E) and data (text near 0x03D9xx); the 6 bytes at 0x0FFB1A-0x0FFB20 (HUNK_END 0x3F2 leftover); the last 3 bytes 0x0FFFFD-0x100000.
