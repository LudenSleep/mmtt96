## Rationale
- Shape: T1 learns the assembler on synthetic, non-game input (cheap, isolates the variable, no firewall exposure); T2 builds the plumbing (listing export + split hook + Makefile deps) on one throwaway region; T3 is the real probe and the encoding map; T4 closes (docs, CI comment, card, negative controls, milestone). Strictly sequential: each consumes the previous one's result.
- T1 self-verifies sizes with label-difference asserts (`if (l2-l1) <> n` / `inform 3`) in the probe source: every listed trap (Bcc .s/.w, abs .w/.l, moveq vs move.l #, addq/subq vs add/sub #, lea/pea abs vs (d16,pc), zero displacement, `(0,An)` vs `(An)`) differs in size, so the assembler's choice is measured without any ground-truth bytes. Same-size opcode choices are checked by disassembling T1's own output with the T2 listing path or by PRM opcode tables; T1's probe file stays in `.run/probe/` (scratch, not kept as a test suite: the game probes are the gate).
- Listing source = Ghidra (it already holds flow, xrefs and switch-table analysis); a new `db.py listing` subcommand plus a headless post-script `scripts/ghidra/Mmtt96Listing.java`, with a Python pass converting Ghidra syntax (`0x` hex, operand spelling) to asm68k syntax. Delta over existing tools: db.py exports symbols only, no instructions; the 1.7 campaign needs exactly this per routine, so it is not a one-time fetch. Output always lands in `asm/src/` (ignored); the script is code, not game data.
- Converter policy: emit the explicit size suffix the original encoding implies on every size-ambiguous operand (Bcc, abs addressing, displacements) once T1 shows defaults differ; out-of-region targets as absolute `$XXXXXX` expressions; in-region targets as local labels. Readability is phase 1.9's.
- Split hook: a region switches to instruction form by the PRESENCE of `asm/src/<id>.asm` (split `--src asm/src`, Makefile `SRC ?= asm/src`, `SRC=` forces all-data). `asm/rom/<id>.asm` stays the wrapper: label `<id>:`, `include` of the source, unchanged `assert_end`; so boundary assert and `sha1sum -c` are untouched. Split must stop rmtree-ing `asm/src/`; `make clean` removes only generated outputs (`build`, `asm/rom`, `asm/main.asm`, `asm/imp.asm`, `asm/.stamp`). Rejected: a tracked override list (a fresh clone without the ignored sources would fail); a top-level `src/` dir (new ignore + firewall surface for nothing).
- Makefile deps (P1.3-1): `$(STAMP)` gains `$(wildcard $(SRC)/*.asm)` (presence changes the split) and `$(OUT)` gains `asm/main.asm $(wildcard asm/rom/*.asm asm/imp.asm $(SRC)/*.asm)`; a hand edit then rebuilds without `make clean`.
- Pin evidence is the game build, not the synthetic probe: a flag set is pinned only when the T3 sources assemble to the original hash from a clean rebuild.
- effort: high on T3 only (1 of 4). Judgment no test arbitrates: choosing probes that cover the trap set, deciding which disagreement is an assembler default vs a needed directive vs a disassembler/converter error, and the hand-written-vs-compiled verdict read from code shape. `expert-fable` is not installed on this tier: the router runs T3 on expert-opus55 (the developer's stated mapping).
- coder opus55 for all (one tier); T4 has small edits but a multi-file change and a gate run.
