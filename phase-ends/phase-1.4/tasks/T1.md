The assembler optimises nothing by default. Every unsuffixed form assembles to its long encoding; every short form needs an explicit suffix or mnemonic. The tables below are per trap class.

Branches and calls (Bcc, BSR, BRA):

- Default (unsuffixed): always .w, backward, forward, near or far
- Force short: `.s` (same as `.b`)
- Force word: `.w` or no suffix
- Unsupported: `.l` ("cannot be this size"); `.s` out of range ("destination is too far away"); `.s` with displacement 0 ("use a word-sized branch")
- Switch that changes it: none (`/o ow+ os+` etc. only warn "Unsupported option")

Absolute addressing (operands and move/cmp/etc. effective addresses):

- Default (unsuffixed): always abs.l, for low addresses, $8000, $FF0000, $FF8000, $FFFF8000, $FFFFF000 and forward `equ` symbols
- Force abs.w: `(x).w` or `x.w`; value must be <= $7FFF or >= $FFFF8000
- Force abs.l: `.l` or no suffix
- Unsupported: 24-bit RAM form `$FF8000.w` is rejected: write RAM addresses as `$FFFFxxxx`
- Switch that changes it: none

Immediates: moveq versus move.l, addq/subq versus add/sub:

- `move.l #imm,Dn` default: stays move.l #imm, even `#0` and `#1`; never moveq
- Force moveq: write `moveq` (range -$80..$7F or $FFFFFF80..$FFFFFFFF; `#$FF` rejected)
- `add/sub #imm,Dn` default: always addi/subi; never the `add <ea>,Dn` immediate form, never addq/subq
- Force addq/subq: write `addq`/`subq` (1..8)
- Address register targets: `add.l #,An` gives adda.l; `move.l #,An` gives movea.l
- Switch that changes it: none (omq+ oaq+ osq+ only warn); `/o wp+` adds pedantic warnings ("ADD should be ADDI"), bytes unchanged

lea, pea, jmp, jsr to a label:

- Default (unsuffixed label): abs.l, even for a label at $0000
- Force pc-relative: `label(pc)`
- Force abs.w: `(label).w` (same size as pc-rel, different opcode)
- Switch that changes it: none (`/o op+` only warns)

Address register indirect and indexed:

- `0(An)` and `(0,An)` default: kept as d16 = 0 (4 bytes)
- Force `(An)`: write `(An)`, or assemble with `/o oz+` (turns every 0(An) into (An), 2 bytes)
- `(d8,An,Xn)` index size default: .w
- Index forms accepted: `d(An,Xn)` and `(d,An,Xn)`; `.l` index ok
- Unsupported: `.b` index size; d8 out of range is an error

Data, labels, includes, alignment:

- dc.w jump-table offsets: `label-label` and `label-base-const` with forward labels assemble correctly
- Odd-address dc.w/dc.l: default `ae+` pads one $00 byte; `/o ae-` packs
- Local labels: `@name` local by default; `.name` is global (redefinition error) unless `/o l+` or `opt l+`, which makes `.` local and `@` global
- Labels: register names (`a1`, `d0`) cannot be labels
- include: resolves against the process cwd only, not the including file's folder; backslash paths ok
- Include search path: none: `/j <dir>` swallows the next argument and warns unsupported
- even, cnop: `even` pads $00; `cnop 0,N` and `cnop 1,4` work
- Unsupported: `align` is not a directive (syntax error); instruction at odd address only warns, rc=0
- Assert: `if (end-start)<>N` / `inform 3,"..."` / `endc` works inside a macro; failure exits rc=1, no output file

Switches and `opt`:

- Accepted silently: `/o <opt>` (comma lists such as `/o oz+,ae-`), `/m`, `/e SYM=val`, `/e SYM`
- Warn, no effect, rc=0: `/k /w /g /l /z /c /d /j`; `/o an+/-`, `ow+ op+ os+ omq+ oaq+ osq+`
- Rejected rc=1: `/q /a /b /f /h /i /n /r /s /t /u /v /y`; `/x` (exe output unsupported); `/o s+`, `/o e+`, `/o m+`
- No size change: `/o c d v w ws s-` (both signs)
- `opt` directive: same option names, comma lists, works mid-file; a bare name without sign is a syntax error (the CLI only warns)

Recommended flag set for T3:

- Switches: none: `clownassembler_asm68k.exe //p <src>,<out>`
- Short forms: always explicit: `Bcc.s`, `(x).w` with RAM as `$FFFFxxxx`, `label(pc)`, `moveq`, `addq/subq`
- ae: keep the default ae+ unless the original has dc.w at an odd address
- oz: never, unless the original uses (An) for every 0(An); otherwise write `(An)` explicitly
- cwd: the source root; every include path root-relative
- Labels: `@` locals
