# T2.c1 — split.py --src + Makefile SRC plumbing

## Changed
- `scripts/build/split.py`: `--src` (default `asm/src`, `""` = all data). Src ids = sorted stems of `<src>/*.asm`; id not a row or compressed row -> `refuse_split` (exit 2), checked before any output is deleted. Prints `split: src <n> regions <ids>` (rstrip when n=0). Wrapper for src rows: `<id>:` + `include "<relpath(src/id.asm, out), forward slashes>"` + `assert_end`. `rmtree(out)` replaced by removal of `<out>/rom`, `main.asm`, `imp.asm`, `.stamp` only. Docstring updated.
- `Makefile`: `SRC ?= asm/src`; `SRC_ASM := $(if $(SRC),$(wildcard $(SRC)/*.asm))`; `asm/.srclist` = `SRC=<val> <sorted ids>`, rewritten via `$(shell)` only when content differs, skipped when `clean` in MAKECMDGOALS; `$(STAMP)` deps + `$(SRCLIST)`; split gets `--src "$(SRC)"`; empty rules `$(SRCLIST) asm/main.asm: ;` (avoid "no rule" after clean); `$(OUT)` deps + `asm/main.asm $(wildcard asm/rom/*.asm asm/imp.asm) $(SRC_ASM)`; `clean` = `rm -rf build asm/rom asm/main.asm asm/imp.asm asm/.stamp asm/.srclist`.

## Verified
- `make clean && make build SRC=` -> `split: src 0 regions`, `build/mmtt96.bin: OK` (.run/logs/t2c1_1a.log)
- `make build SRC=` again -> only sha1sum line, OK (t2c1_1b)
- scratch `.run/t2c1_mksrc.py` -> `asm/src/header.asm` (256 B, dc.b from ROM); `make build` -> `split: src 1 regions header`, OK; wrapper `include "src/header.asm"` (t2c1_2a)
- `touch asm/src/header.asm; make build` -> assemble only, no split, OK (t2c1_2b2). First attempt t2c1_2b did not rebuild: touch landed in the same second as the bin (make mtime granularity on this Windows make), not a dep bug.
- `make build SRC=` -> re-split src 0, OK (t2c1_2c); `rm asm/src/header.asm; make build` -> re-split src 0, OK (t2c1_2d)
- `make clean` -> `asm/` left with `src/` only
- refusal: `split.py --src <dir with bogus.asm>` -> `split: refused: ... 'bogus' is not a region row`, exit 2
- `tools/audit_public.py` exit 0; `git ls-files asm build expected` empty
- scratch src removed (`asm/src` deleted), final `make build` OK (t2c1_2e)

## Notes
- generalizable: make on this host compares mtimes at ~1 s granularity; an edit within the same second as the last build is missed.
- `make clean build` in one invocation skips the srclist write (goal contains clean); empty rule covers it, stamp is rebuilt anyway.
