## Encoding classes (default)
- Bcc/BSR/BRA unsuffixed: always .w, backward/forward/near/far. `.s`=`.b` short; `.l` rejected "cannot be this size".
  .s too far: "destination is too far away"; .s disp 0: "cannot be 0 bytes away ... use a word-sized branch".
- Unsuffixed absolute: always abs.l (low, $FF8000, $FFFF8000, $8000, $FF0000, $FFFFF000, forward equ).
  `(x).w` or `x.w` -> abs.w; .w value must be <= $7FFF or >= $FFFF8000 (24-bit $FF8000 rejected): write RAM as $FFFFxxxx.
- `move.l #1,d0` stays move.l #imm; moveq only explicit (range -$80..$7F / $FFFFFF80..; $FF rejected).
- `add/sub.w #imm,Dn` -> addi/subi (never add <ea>,Dn #imm form, never addq). addq/subq explicit only (1..8).
  `add.l #,An` -> adda.l; `move.l #,An` -> movea.l; `move.l #0,d0` stays move.l.
- lea/pea/jmp/jsr unsuffixed label -> abs.l even for label at $0000; `label(pc)` -> pc-rel; `(label).w` -> abs.w
  (same size as pc-rel, opcode differs).
- `0(An)`/`(0,An)` -> d16=0 by default. Index unsuffixed -> .w; `.l` ok; `.b` rejected; d8 range enforced; `(d,An,Xn)` form ok.
- dc.w label-label / label-base-const with forward labels: correct.
- Local labels: '@' default; `.x` is global by default (redefinition error).
- Register names (a1, d0...) cannot be labels.
- include: resolves vs process CWD only, not including file's dir (nested `include "inner.asm"` in inc/ fails;
  `include "inc/inner.asm"` works; running from repo root fails). Backslash paths ok.
- even pads $00; cnop 0,N pads $00; cnop 1,4 works; `align` not a directive (syntax error).
  Instruction at odd address: warning only, rc=0.
- Assert form if/inform 3/endc works inside a macro.
