## Two points the rules wave left open

The banner quirk (T14). The "Play Off!" banner routine fn_007bdc runs only while the playoff timer is nonzero. During a point pause it is meant to push the banner into its exit phase: it sets the timer to 352 when the banner is not yet past 348. But it compares a value of 40 to 60 derived from the timer, not the timer itself, with 348; the test is therefore always true and the timer is set to 352 on every frame of the pause, holding the banner at the start of its exit phase until the pause ends. It matters only when a point is scored while the banner is still on screen, and then that point ends the match anyway. This is a reading of the code (hypothesis); a writer run on the timer from the P023 variant, where a point pause is already running when the banner starts, would show one write of 352 per frame. A matching decompilation keeps the behaviour as it is; the doc records it as a quirk.

The finishing words ram_FFD2BA to ram_FFD2C0 (slot index or place order). T14 found two uses that seemed to disagree: the ranking routine treats the words as place order (first word = winner's slot + 1), while the end-of-race fill seemed to treat them as one word per slot. This task resolves the conflict on paper: the fill gives empty word k the value 1 + the position of 2k in ram_FFD250, and ram_FFD250 holds each slot's place x 2 (written by the ranking routine), so the position of 2k is the slot in place k and the fill also writes place order. The one challenge writer run agrees: the first word was first written the frame after slot 3 finished (2416), the second when slot 2 finished (3048), the third and fourth only by the fill at 3099; under slot indexing slot 3's finish would have written the fourth word first. It stays a hypothesis (one run, no values recorded at each write, and the reading assumes places count from 0); the doc's open question names the settling runs.
