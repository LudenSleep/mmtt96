## Outcome in plain English

A course in this game is a number from 0 to 66. When a race loads, the game uses that number to pick one entry from
each of about thirty lists in the cartridge: the pictures of the ground, the map of which picture goes where, the
map of where the walls and the off-track areas are, the invisible lines that count laps, the route the computer cars
follow, the car pictures, the handling numbers and the music number. One of those lists is a single yes/no byte per
course, the half-scale flag. When it is yes, the game draws everything at half size (it has no hardware zoom, so it
does this in software), which is what makes a course "Mini Micro".

Three new measurements this task:
- Courses 50, 53 and 54 have the half-scale flag but are in no menu list. Loaded by force, all three are complete
  and raceable: 50 is a large pool table (baize, balls, a corner pocket, a cushion rail), 53 and 54 are garden
  courses (wooden planks on a lawn, hedges). They are finished Mini Micro courses that the menus never offer (P113).
- A construction-kit race normally has the flag forced to no by one store in the kit's race setup (the only write
  of the flag in a kit race). Changing it to yes during a test run gave a working half-scale race (timer, driving,
  collisions all fine), but some squares drew black or with the wrong pictures (P111).
- The kit's "kind-5 art variant", which looked like a theme switch, changes only the ground under the whole course:
  brown woodgrain, red carpet, grey floor tiles, grass. None is a pool table (P112).

## What a new Mini Micro level needs

There are three roads, from cheapest to most work. None of this is an instruction to patch the ROM; it is what the
evidence says would have to change.

1. Offer a hidden course (data only, probably). Courses 50, 53 and 54 already exist complete. To make one selectable
   it needs a place in a menu list (the time-trial list holds 27 course numbers and the course select stops at 27;
   swapping an existing entry is data only, adding a 28th would also change one number in the code) and a name and
   class label to show. Not yet tested through a menu; only by setting the course number directly.
2. A new cartridge course (data and art, no code). Five course numbers (17, 32, 35, 38, 40) are empty, so up to five
   new courses fit without moving anything. Each needs an entry in every per-course list: ground pictures and the
   blocks built from them, the two maps (pictures and walls), the lap lines, the computer cars' route map, the car
   picture record, the handling and music record, the start positions, colours, a few yes/no switches, and the
   half-scale flag set to yes. The art is the real work: the half-scale drawing keeps only a quarter of each block's
   picture pieces, so ordinary art looks coarse, and Pool Slalom's art was drawn specially (about 40 % less picture
   data than the full-size pool table) with a smaller car drawn inside the same sprite. The game code is unchanged.
3. A Mini Micro construction-kit course (a small code change and new art). The kit's race setup must write yes
   instead of no to the half-scale flag, chosen by some option of the saved course (the 147-byte record has no spare
   field known, so the choice would reuse an existing one, for example a ground theme value, or the record format,
   password and save slots would change). The 16 kinds of track piece need pictures drawn for half scale (the
   current ones draw some squares black), and a pool-table look needs a new ground picture set, since none of the
   four existing ones is a pool table.

## Names of the group and their evidence

Evidence classes: measured = confirmed by three or more emulator runs or a cited confirmed claim; code = read from
the listing (several code sites agree, no runtime run of its own); spec = Mega Drive hardware documentation.

- `ram_half_scale_flag` — the per-course yes/no byte that switches half-size drawing on. Measured.
- `ram_maps` — the unpacked maps block: width, height, picture map, wall map. Measured.
- `maps.width`, `maps.height` — the map's size in 32-pixel blocks. Measured.
- `ram_block_map_ptr` — where the wall (collision) map starts. Measured.
- `ram_block_patterns` — the 256 small wall patterns the wall map refers to. Measured.
- `decrunch_buf` — the scratch area the decompressor unpacks into. Measured.
- `imp_decrunch` — the decompressor for the packed level data. Code (signature anchor).
- `ram_dir_map` — the computer cars' direction map, one byte per block. Measured.
- `dir_map_read` — reads one byte of that direction map for a computer car. Measured.
- `ram_cp_list_buf` — where the lap-counting lines are unpacked. Measured.
- `ram_cp_lists` — pointer the lap code uses to find those lines. Measured.
- `ram_cp_count` — number of lap-counting lines on the course (176 or 88). Measured.
- `ram_cp_ahead_max`, `ram_cp_wrap_hi` — the two limits used to order cars by progress. Measured.
- `ram_bounce_sw` — per-course switch for the bounce behaviour. Measured.
- `ram_kit_course` — the construction kit's 147-byte course record in work RAM. Measured.
- `kitcourse.map` — the 16 x 16 piece map inside that record. Code.
- `kitcourse.artvariants` — 2 bits per piece kind choosing its picture variant. Code.
- `kitcourse.vehicle` — which of the kit's 10 cars is raced. Code.
- `kitcourse.palettemode` — the weather/colour byte (3 and 4 change colours and grip). Code.
- `kitcourse.topspeed`, `kitcourse.grip`, `kitcourse.accel` — the three handling options. Code.
- `ram_saved_courses` — the first of nine save slots in the RAM copy of the save chip. Code.
- `savedcourse.course`, `savedcourse.bytesum`, `savedcourse.zero` — a slot: the record, its check byte, a zero. Code.
- `ram_eeprom_image` — the full 2048-byte RAM copy of the save chip. Code.
- `eeprom_save` — writes that copy back to the save chip with fresh check sums. Code.
- `eeprom_data_in` — the save chip's data line, read at power-on. Measured.
- `kit_race_setup` — prepares a kit race: course 66, handling, flag, lap lines, maps. Code.
- `kit_piece_blocks` — builds the pictures of the 16 piece kinds for a kit race. Code.
- `kit_race_maps` — builds the 72 x 72 race maps from the piece map. Code.
- `kit_edit_maps` — builds the small maps shown in the editor. Code.
- `kit_circuit_check` — the "is this a legal circuit" walk behind Test Course. Code.
- `kit_cp_build` — lays the lap-counting lines along the kit circuit. Code.
- `z80_busreq` — the line that pauses the sound processor so the main CPU can write its memory. Spec.

Not named, on purpose: the sound mailbox, sound senders and course tables keep neutral names (`z80_A01E00`,
`fn_015830`, `data_04693E` and so on) because their meaning rests on one probe each or on code reading alone; the
kit race entry `fn_001978` stays neutral because it shares a signature group with the race main loop (T22).
