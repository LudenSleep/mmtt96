## How sound and music are driven

The Mega Drive has a second, small processor (the Z80) that this game uses only for sound. At power-on the main
processor copies a 5228-byte sound program (the driver) into the Z80's memory and waits for it to say it is ready.
After that the main processor never touches the sound chips: it drops short numbered commands into a mailbox in the
Z80's memory (play sound n, stop sound n, and every race frame a value that sets the engine's pitch from the car's
speed). The driver loops, picks up each command and plays it on the FM sound chip, including recorded samples through
its sample channel; the simpler PSG chip was not used in the run measured. Its music, effect and sample data sit in
one 62 KB block of the cartridge (020000-02FA85 hex), which the driver reads directly, 32 KB at a time. Request numbers
fall into three bands: engine sounds (0-3 seen, taken from the course record and tied to the vehicle), menu tunes and
jingles (5-15 hex, sent by the screens), and effects (4A-AB hex, sent by race events). The driver's internal format
(which bytes are scores and which are samples) is not decoded; that would be a project of its own.

## Menus in one page

The game's front end is a chain of screens, each waiting for a pad choice. The main menu offers 1 Player, 2 Player
and Extra Options (with a J-Cart also 3 Player, 4 Player and 4 Player Teams). One player picks a game type
(Challenge, Head To Head, TT Challenge, League, the four Pro forms, TT Single Race) and plays a season: driver
select, course preview with a small moving map, the race, the result, and the lives, game over or season end screen.
Several players pick Single Race, one of seven Tournaments (Rookie Races, Jets N Jumps, Mighty Mix, Monster Courses,
Turbo Cars, Pro Tournament, Mega Comp; first to 3, 5 or 7 wins), TT Single Race or TT Tournaments (players race the
clock in turn). Extra Options holds Party Play (Knockout for 4-16 drivers in a bracket; with a J-Cart also the
eight-car game for 8, 6 or 4 players), Player Stats, TT Stats, the Construction Kit and Clear Storage. Every menu
steps with Up and Down (sound 87 hex) and chooses with Start (sound 88 hex); left alone for about half a minute it
starts the demo. Records, names, unlocked courses and kit courses are kept on the cartridge's save chip.

## Effects in one page

There is no general effect system. Sound effects are numbered requests to the sound processor. Visual effects are
made from extra sprites, palette changes and rewrites of the course map during the race, each a small routine run
every frame, mostly a per-course routine ("course hook"): tyre marks (likely) that fade in four steps, the
construction kit's weather (Rainy: scattered items and random sounds, with tyre marks switched off; Windy: drifting
objects; Frosty: other colours and low grip; Lightning: random white flashes), splashes on the sinking courses,
bursts of falling items, animated scenery with looping sounds, colours that change with where the view is, course
pieces that open and close, objects that shake before they open into holes, and cars drawn higher the faster they
go on three courses. None of the visual effects has been measured in a run yet; all are read from the code.

## Names of the group and their evidence

Evidence classes: measured = confirmed by three or more emulator runs or a controlled probe; code = read from the
listing at several agreeing sites, no run of its own; spec = Mega Drive hardware documentation.

Start-up and hardware set-up:
- `init` — the start-up code at 000200 hex: the standard Mega Drive set-up of video chip, memory and sound processor. Measured (boot runs, breakpoint).
- `init_table` — the register values and commands the start-up code loads. Measured (read tap, 3 runs).
- `vdp_init_regs`, `vdp_clear_vram`, `vdp_clear_cram`, `vdp_clear_sprite_table` — set the video chip's registers, clear its picture memory, its colours, its sprite list. Code.
- `vdp_set_plane_a_base`, `vdp_set_plane_b_base`, `vdp_set_window_base`, `vdp_set_sprite_base`, `vdp_set_hscroll_base` — tell the video chip where each background layer, the sprite list and the scroll table live in its memory. Code.
- `clear_ram_block`, `clear_ram_block_01F840` — clear a fixed stretch of work memory (twins with different start points). Code.
- `nullsub`, `nullsub_012EE0`, `nullsub_012EE8`, `nullsub_012EEE` — routines that do nothing (a lone return), kept by structure. Code (executed in coverage runs).
- `imp_decrunch`, `imp_decrunch_core` — the unpacker for the cartridge's packed pictures and level data (Imploder format). Measured (coverage, 3 runs).

Sound processor:
- `z80_ram` — the sound processor's own 8 KB of memory. Spec, and measured (driver upload seen in 3 MAME and 3 BizHawk runs).
- `z80_busreq`, `z80_reset` — the two control lines the main processor uses to pause the sound processor (to write its memory) and to hold it in reset. Spec.
- `z80_boot_stub` — a tiny placeholder program loaded into the sound processor at start-up. Code (start-up copy loop).
- `z80_upload_driver` — copies the sound driver into the sound processor's memory at power-on. Measured (coverage, 4 runs).
- `z80_driver` — the sound driver program itself, 5228 bytes, stored in the cartridge and run by the sound processor. Code (upload source and length).

Save chip and J-Cart (reviewed with Input in T21, listed here because the menus use them):
- `eeprom_save` — writes the records, names and kit courses to the cartridge's save chip. Code (several agreeing sites).
- `ram_eeprom_image` — the work-memory copy of the save chip's 2048 bytes. Code (three datapoints).
- `eeprom_data_in` — the cartridge address the save chip's data bit is read from. Measured (P100, 3 runs).
- `jcart_detect`, `jcart_read`, `ram_jcart_found` — find the J-Cart (two extra pad ports on the cartridge) at power-on, read it every frame, and the flag that says it is there; the main menu offers 3 and 4 players and the party list only with it. Measured.
- `ram_irq6_wblock` — the work-memory block written during the frame interrupt; a value 7 in its first byte also unlocks the J-Cart menu lists. Measured for the range, code for the menu use.

Modes reached from the menus (named in earlier groups):
- `eight_car_race` — the race of the eight-car game (main menu value 7): eight cars, four pads. Code.
- `kit_race_setup` — sets up a race on a construction-kit course (internal course 66). Code (T22).
