## Adding a Mini Micro (pool-table) course: what is known now

This is a plan of what would have to change, not an instruction. Confidence is marked on each point.

(a) The switch is data (confirmed). Each internal course number has one byte in a 67-entry per-course byte table that sets the half-scale flag at level load. Only course numbers 19 (Pool Slalom), 50, 53 and 54 carry it. Experiment P105 switched the flag on for Ferry Fiasco: the race worked at half scale, the scenery was recognisable but coarser and the car stayed at its normal drawn size. So the engine needs no code change to show an existing ROM course at Mini Micro scale.

(b) The art is the real work (hypothesis, well supported). The game's art is drawn for full size; the half-scale drawer keeps a quarter of each level block's tiles, which is why Ferry Fiasco looked coarse. Pool Slalom's own art is made for this: its car drawing is about two thirds the normal size inside the same 24 x 24 sprite, its billiard balls about half the size of Ball Chase's, and it loads about 40 % less tile graphics. A good-looking Mini Micro course needs level art and car art drawn for half scale.

(c) Room is limited (hypothesis, from the table sizes). There is no course count: every per-course table has exactly 67 entries, numbers 0 to 66, packed against the next table. Five numbers are free (17, 32, 35, 38, 40), so up to five new courses fit without moving tables; a new course needs an entry in every per-course table (about thirty) and a place in a course list to be selectable (the time-trial list holds 27 and wraps at 27 by a constant in the code). Going past 67 means extending and moving every table and changing the table addresses in the code.

(d) The construction kit (hypothesis, untested). The kit's race is course number 66, built in RAM at normal scale, and its 147-byte record has no scale field. A Mini Micro kit course would need the flag set for course 66 from some kit option or theme bit (the record has bits for four piece-art themes) plus a new set of 16 half-scale piece graphics: a small code change plus art. Whether the kit's race setup reads the flag table at entry 66 at all is not yet traced, and whether any of the four kit themes is already a pool-table theme is unknown but easy to check.

First cheap experiments, in order: (1) a writer run on the kit race watching the half-scale flag, then the same race with the flag forced to 1 by a breakpoint after the kit setup, in a throwaway run (never a tracked ROM patch); (2) view the editor's four themes in turn to see whether one is a pool table; (3) swap one theme's piece art for another's at load, as T10 swapped blobs. None needs new tooling.
