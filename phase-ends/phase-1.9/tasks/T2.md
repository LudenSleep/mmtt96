Findings:
- Scroll writers (3/3 boot runs): hscroll table: one command per race frame at writer pc 03ECF6 (2 data words, one address: consistent with whole-screen scroll for planes A and B; also 0078C4 x10 at setup); VSRAM: 03ED2C (2 words per frame; 0078DC, 000272 setup); reg 0B (scroll mode): 01F8AC, 0045EC, 00023E; reg 0D (hscroll base): 01F92C, 00023E.
- Sprite table: DMA every frame by 01FABC from RAM buffer FFCB7C (the sprite list built in RAM); CPU writes by 01F952 x12. 01FABC is the shared DMA command writer (regs 13-17 set at 01FA82..01FAA0).
- Plane A writers 010B0A, 010ACC, 013AB6 (most), plane B 013AB6; CRAM 0078F8 every frame.
- The game writes ROM address 000000 once at frame 595 (writer pc 03F32E, 3/3 boot runs); purpose unknown.
- `ram_frame_counter` FFC220: no write in boot frames 3-7, then every frame; writer 01F9EA.
- Race states are deterministic: identical base/variant from `challenge_r1` diverge in 0 words over 400 frames (P006).
- Accelerate census (P005, challenge_r1, P1 B held 1-400 vs idle): 325 words diverge; earliest FFC20A, FFD376, FFD764, FFEC6C (frame 2), FFD36C/FFD36E/FFD680 (3), FFD30C-FFD316 (51), FFCC16.. (52). Full list `.run/oracle/t2p_var_20261013T165126_diverge.tsv` (regenerate if gone).
- MAME 0.289 `:gen_vdp` (sega315_5313) has no Lua state entries.
Gotchas:
- generalizable: MAME Lua `dofile` executes in the global env, not the autoboot script's env; to share globals with a helper script use `loadfile(path, "t", _ENV)()`.
- generalizable: Mega Drive DMA source registers 15-17 may encode the RAM mirror (FExxxx); fold E00000-FFFFFF to FF0000 | low 16 bits.
- generalizable: a "never written" negative control must be checked on a boot run too: this game writes ROM 000000 once.
- generalizable: a diff probe needs a positive control (a poke that must diverge) besides the identical pair, or a broken diff passes.
