- Blob list via env `ORACLE_BLOBS` (`.run/oracle/decrunch_all_blobs.txt`, hex starts from manifest compressed records); `ORACLE_MODE=all` set by decrunch.py only around the run.
- Spin = first `bra.s *` (word 0x60FE) found in ROM by Lua scan (address not recorded).
- bp rts 0x035448: `printf IMPOUT a0,d1,d0 ; save <trace>_ret.bin,a0,d1 ; pc=<spin> ; go` — the first natural call's return is diverted; the natural caller's return address stays on the stack, never popped.
- bp spin, condition `temp1==1`: `temp1=0 ; a0=temp0 ; a1=FF0100 ; pc=035416 ; printf IMPIN ...`. frame_done renames the buffer to `_blobN.bin`, emits `forced`, stages the next blob with `temp0=<start>`, `temp1=1` (debugger console expressions). Stall guard 1200 frames per blob.
- Gotcha: after a `pc=` write in a bp action, the bp at the new pc (0x035416) does not fire; IMPIN therefore is printed from the spin action. generalizable: candidate cookbook entry (forced-call harness via spin + temp vars).
- Natural call hijacked at frame 35 (src 0x0FDAAE, the r0375 blob); forced blobs frames 39-1656; SP at forced entry 0xFFFFEE.
