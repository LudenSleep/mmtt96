# T3.c1 — decruncher convention, natural-call oracle, RAM claim

## Convention (from ghidra/mmtt96 listing, scratch `.run/ghidra/imp_listing.txt`; live runs agree)
- `imp_decrunch` 0x035416 (wrapper): in A0 = IMP! blob (ROM), A1 = dest buffer (RAM). No IMP! magic: D1 = 0, rts at 0x035448, nothing written. Else copies the blob to A1 as longs ((endOffset+0x32)/4), then calls core with A0 = A1 = dest (in-place decode). Out: D1 = rawSize, A0 = dest, D0 = -1 ok / 0 fail. Clobbers D0, A1 (left pointing at freed stack scratch), A5 (= dest). Preserves D2-D7, A2-A4, A6. Single rts at 0x035448. Dest must hold max(rawSize, blob size) bytes.
- `imp_decrunch_core` 0x03544A: in A0 = blob, A1 = output start; decodes backwards; saves D2-D5/A2-A4; 0x1C bytes stack scratch; out D0 = -1 ok / 0 bad magic or input pointer not at start; flags from tst.l D0.
- 19 call sites (Ghidra refs). Samples: 0x013B02 / 0x0139BE / 0x04157C load A1 = 0xFF0100 then jsr and read the first words of the buffer; 0x001AC8 A1 = 0xFF750C; 0x00F06A tail-calls via jmp (A1 = 0xFF6D38). Other dests seen statically: 0xFF3308, 0xFFDF7A, 0xFFA0AC, 0xFF4308.
- Live: SP at entry 0xFFFFAC-0xFFFFF2 (stack at top of RAM).

## Safe scratch for a forced-call harness (c2)
- Dest 0xFF0100 (the game's own common buffer). Max over all 368 blobs of max(rawSize, blob size) = 27840 (r0211) -> 0xFF0100-0xFF6DBF. Stack lives at 0xFFFFxx, far above. Natural calls observed only up to 0xFF4CC5.

## Changes
- `scripts/oracle/lua/decrunch.lua` (new): mode natural (env ORACLE_MODE, other modes emit error). bp entry `printf IMPIN a0,a1,sp,d@sp`; bp rts 0x035448 `printf IMPOUT a0,d1` + `save <trace>_ret.bin,a0,d1`; frame_done renames to `_callN.bin`, emits `{ev:call,n,frame,pc_entry,ret,src,dest,dest_in,sp,size,file}`. Addresses masked to 24 bits (MAME prints RAM regs as FFFFxxxx). If two calls return in one frame only the last buffer is kept (earlier: file null, skipped, not a datapoint); not observed.
- `scripts/oracle/decrunch.py` (new): `--natural [--runs 3] [--frames 1200] [--write [--tsv]]`; matches src to manifest compressed starts, sha1/size of saved buffer to the decoded record; exit 1 on mismatch/unknown src/no done/<3 calls. `--write` rewrites `config/oracle/decrunch.tsv` (columns `parent sha1 run pc_entry dest size name`; plan shape + `size`,`name`; pc_entry = caller return address). `--all` left for c2.
- `config/oracle/decrunch.tsv` (new, 39 rows): written by `--natural --write` runs decrunch_20261011T224837, decrunch_20261011T224840, decrunch_20261011T224842 (via the first run before `--write` existed: it wrote unconditionally then).
- `config/maps/ram.tsv` (new): claim `decrunch_buf_ff0100` 0xFF0100-0xFF4CC5 kind `decrunch_dest`, probe decrunch.lua, those 3 runs, verified.
- `scripts/oracle/check_maps.py`: kind `decrunch_dest` (datapoints from `--decrunch` default config/oracle/decrunch.tsv; run needs >= 1 call with dest == addr_start, all such end <= addr_end); `--live` reruns decrunch.lua and requires decrunch.match clean. Refactor: `agrees_run`, `live_rows`.
- `config/ghidra/comments.tsv`: plates at 0x035416, 0x03544A (prose + register names). `symbols.tsv`: label `decrunch_buf` 0xFF0100 source `emu:decrunch_buf_ff0100`.

## Notes for expert
- MAME debugger: `a7` is not a symbol (parses as hex 0xA7); use `sp`. `d@sp` reads the return address. `save f,a0,d1` works in a bp action. generalizable: candidate cookbook entry.
- decrunch.py without `--write` never touches tracked files, so the gate is repeatable; ram.tsv datapoints stay valid.
