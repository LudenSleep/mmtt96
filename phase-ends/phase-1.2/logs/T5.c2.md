## Gotchas
- harness: EmuHawk shows a modal "Warning" (Couldn't find firmware GEN+CD_BIOS_EU, optional Mega-CD BIOS) on every cart load and again after reboot_core; it blocks Lua start (process alive, no output, timeout). bizhawk.py auto-closes exactly that dialog. Precondition run in the brief likely had it clicked.
- generalizable: BizHawk `client.reboot_core()` keeps the Lua script running but drops memory callbacks registered before it: reset first, then register (brief said register then reset; reversed, evidence: both facts `none` in run bhdev_20261012T081926).
- generalizable: GPGX exec-any callback reports 000000 first after reset, then the reset PC; same shape as MAME's trace.
- harness: works inside the Bash sandbox; no sandbox override needed.
