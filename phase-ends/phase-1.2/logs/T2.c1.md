- MAME `soft_reset()` re-runs the autoboot script; earlier frame callbacks persist (p4 scratch: "load" printed per reset). boot.lua guards with global `ORACLE_BOOT_LOADED`. generalizable:
- bp action `printf "...",pc` prints insn+2 on m68000 (bp 0x200 printed 202) -> address baked into text. generalizable:
- Soft-phase trace starts exactly at 000000 (`pre_reset` 0 in all runs).
- Init split: scratch trace (10 frames) executed PCs in [0x200,0x2C4) max 0x00028C = `bra.s` to 0x0002FA (2 bytes) -> init ends 0x00028E; RAM clear loop 0x25C/0x25E spans ~2-3 frames.
