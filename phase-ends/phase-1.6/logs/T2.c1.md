## Decisions
- Exact layer = sha1 of body bytes only; an overrunning insn is tokenised whole (normalised/sequence). Overrun = 0 on real data, so moot.
- Registry `group` column = group id in the row's layer (`fE..` for layer exact, `fN..` for normalised); evidence default uses the normalised group id. Group ids are defined for singletons too (formula), so `check` recomputes them uniformly.
- propagate membership comes from a scan of ROM_DEFAULT; gate 1 recomputes the member bodies (same start/end) from `--rom`. Otherwise a flipped byte would just drop the member from the group instead of refusing.
- `db.py listing` gets `--rom <--rom>`; `make build` uses the default ROM. `SRC=.run/signatures/src` works (split.py relpath include); the asm/src fallback was not needed. src dir removed in `finally`. Child output -> `.run/signatures/propagate.log`.
- pair control row: first function in `.run/signatures/functions.tsv` with nN >= 2 (fresh scan in the pair).
