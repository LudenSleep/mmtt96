## Probe (C0009), scratch `.run/t3/probe*.asm`, asw -q -xx -n -U, per-case size asserts
- armed: wrong expected size -> rc=2 `error #9990` (asserts live).
- abs.w with equ `$FFC220` and equ `$FFFFC220`: both 4 bytes, same extension word; equ `$001234` .w: 4 bytes.
- abs.l: equ `$FFC220` -> high byte 00; equ `$FFFFC220` -> high byte FF; equ `$001234` -> 00.
- abs.w with equ `$C00004` (not sign-extendable): size assert fails (AS silently emits a longer form) -> must never be substituted.
- Rule adopted (24-bit equates): abs.w -> name iff (word sign-extended to 24 bits) == named address; abs.l -> name iff 32-bit value <= $FFFFFF and == named address; else raw hex. Immediates raw.
