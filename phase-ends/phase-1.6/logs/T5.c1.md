## Decisions / gotchas
- Capstone reports `(d8,An,Xn)` with d8 = 0 as `M68K_AM_AREGI_INDEX_BASE_DISP` (433 sites; 213 nonzero as INDEX_8_BIT); same 68000 brief encoding -> both map to `d8anxn` (PC analogue -> `d8pcxn`). Unknown operand kinds render `?<type>.<am>` so they surface as unmapped, never silent.
- Branch forms keep `:none` when the displacement was the only operand (`bsr.w:none`); dbcc keeps `dn` (`dbcc.w:dn`).
- gotcha generalizable: module name `encodings` shadows stdlib `encodings` on import (already loaded at startup -> `import encodings` returns stdlib). Running the script directly is fine; importing it needs `importlib.util.spec_from_file_location`.
- Class membership for evidence: A = cmp.{b,w,l}:imm,dn; A2 = addi/subi/andi/ori x:imm,dn; B = movem with d16pc; C = ori/andi/eori with ccr/sr; D = d8pcxn; E = d16an0.
