## Findings
- clownassembler: v1.1.3, published 2026-10-02 (GitHub API). Licence AGPL-3.0-or-later (redistribution OK under AGPL). Assets: clownassembler.exe 126,976 B; clownassembler_asm68k.exe 131,072 B at https://github.com/Clownacy/clownassembler/releases/download/v1.1.3/clownassembler.exe and .../clownassembler_asm68k.exe (raw exe, no archive; arch not verified, presumably x86/x64 PE). Source: portable C89, make or CMake, Flex/Bison only to regen parser. clownassembler_asm68k mimics SN 68k CLI; the other has a simpler custom CLI. Output format/flags not verified (asm68k CLI emits raw binary `asm68k /p src,out.bin`-style). Forum post: assembles s1disasm asm68k branch and Sonic 2 Nick Arcade proto unmodified; only a drop-in for projects avoiding asm68k's exotic features; Z80 macro issues fixed as of 2025-07-28.
- vasm: latest found v2.0 (Oct 2024, amiga-news); no 2025/26 release seen; unverified whether newer. Author offers Windows binaries (per amiga-news 2023) but exact URL not verified; otherwise compile (Visual Studio nmake makefile.win32, or `make CPU=m68k SYNTAX=mot`). Licence: free for non-commercial/own use with redistribution restrictions on the source per its copyright text (not verified, check before bundling in repo/CI; CI would download from author site). Raw output: `-Fbin`. 1.9a (2022): m68k -no-opt overrides "opt o"/"opt a" directives. 1.9e: bin/ihex/srec default ORG 0. m68k optimises by default (e.g. branch/displacement size, move.l->moveq in size opt); for byte-matching use `-no-opt` (and for data-only it is irrelevant).
- Macroassembler AS: Linux packages show 1.42 Bld 232 (SUSE), licence GPL-2/3. Needs p2bin (shipped with it) to produce raw binary. Windows binary download and exact URL not verified. s1disasm (AS branch) and s2disasm build via build.lua/build.bat with helper tools in build_tools/ (s1: `-p=FF -z=0,kosinski,...`; s2: `-p=0 -z=0,saxman...`), flags of p2bin-style tools. s1disasm has both an asm68k branch and an AS branch; s2disasm uses AS (build_tools bundle, Lua 5.3 for build.lua). AS adopted by sonicretro for portability since asm68k is a proprietary old EXE.
- SN asm68k: proprietary, no redistribution rights found; used by s1disasm asm68k branch (Hivebrain/Git lineage); Windows-only (Wine on Linux). Not suitable for CI.
- Common syntax subset: `dc.b $12,$34`, `include`, `incbin`, `even`, `org` are accepted by all four in Motorola syntax; AS needs `cpu 68000` and its own `ORG`/`PADDING` semantics, and AS `include`/`incbin` use quoted paths, `even` supported. Not verified from primary docs; verify empirically.
- Gotchas: asm68k vs AS not source-compatible (AS port required rewriting); branch size selection differs (asm68k/vasm auto-shortening vs explicit .s/.w), matters in phase 1.4 not all-data.
- NOT FOUND: dc.b performance/line-length limits for ~1 MiB, determinism statements, vasm Windows URL/size, AS Windows URL/size.
