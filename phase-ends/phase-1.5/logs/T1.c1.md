## Design notes
- Plant = first Ghidra insn grows by 2, next row shifts +2 (or is absorbed if 2 bytes) -> 1 truncation + 2 phantoms.
- Ghidra targets masked to 24 bits before membership test (abs.w sign-extension).
- Capstone 5.0.7 core emits `dc.w` for rejected words (020+ opcodes, line A/F); mapped to `invalid`.
- Only raw spelling difference found on verified scope: Ghidra `dbf` vs Capstone `dbra` (443 sites) -> alias `dbra->dbf`. Ghidra otherwise spells cmpi/movea/etc. like Capstone; the brief's aliases are kept (apply to both sides).
