## ghidra_db
- `PY scripts/ghidra/db.py {probe|rebuild|export|roundtrip|analyse|listing}`
- `PY scripts/ghidra/classify.py {seeds|merge}`
- Headless Ghidra 12.1.4 db in `ghidra/` <-> tracked `config/ghidra/*.tsv`.
- `probe` = precondition; `roundtrip` exit 0 iff identical.
- `rebuild` order (T34.c2): preScript `Mmtt96Apply.java` (blocks, kind=function symbols, comments, regions) -> auto-analysis -> any `analyse` postScript (`Mmtt96Seed.java`) -> last postScript `Mmtt96Apply.java ... labels` (kind=label symbols). A label never seeds or names a function; at an analysis-made default function entry the label is created in the function namespace then moved to global (a direct global label would rename the function). Markers `.run/ghidra/<project>.apply.ok` + `.labels.ok`.
- `listing` -> AS text, asw self-check (feeds ignored `asm/src/<id>.asm` in `make build`).
- `listing --all-code` (no ids): every regions.retail.tsv row kind=code (verified + inferred); deletes stale `<out>/*.asm` first. Run by `make src` (`asm/src/.stamp`, a prereq of the split when `SRC=asm/src`); failure -> `asm/src` removed, `make:` error naming the regions, exit 1.
- Comments: `config/ghidra/comments.tsv` `plate` -> `; <text>` line(s) above the line at its addr (above its `L_` label; `\n` splits lines); `eol` -> `<insn>\t; <text> ; $ADDR` (trailer last). Other types not rendered; addr inside a region but not a line start -> `listing <id>: comment $ADDR not at a line start (unrendered)`; non-ASCII text -> error exit. Bytes unchanged (self-check).
- Missing Ghidra install -> one-line `db: no Ghidra at <dir>` error.
- Classification pipeline: `classify.py seeds` -> `db.py analyse` -> `classify.py merge` (gap code/data rows, ghidra mirror).
- `classify.py seeds` rewrites `.run/ghidra/seeds.tsv` only when missing or different (prints `seeds unchanged|rewritten`); `census.py` runs it first (unless `--no-refresh`), so a fresh clone or a damaged seeds file is regenerated and the newer seeds re-run `db.py analyse` (T2 gap 2).
- A failed `db.py analyse` removes `ghidra/mmtt96_seed` and its marker `.run/ghidra/mmtt96_seed.seed.ok`; `listing` prefers the seed project only when the marker exists (T2 gap 3).
- `db.py mirror` also rewrites `config/ghidra/regions.tsv` from `config/regions.retail.tsv` (idempotent; health pair `mirror`).
- Env: `MMTT96_GHIDRA_PROJ` = project dir (default `<repo>/ghidra`; a path element starting with `.` is refused by name: Ghidra rejects it, so a clone under `.run/` sets this to a dot-free dir); `GHIDRA_INSTALL_DIR` = Ghidra install; `JAVA_HOME` or java on PATH, else `MMTT96_JDK_PARENT` (dir holding `jdk-21*`).
- `config/oracle/decrunch*.tsv` key `parent_start` (region start hex `0x%06X`), resolved by start in manifest.py/decrunch.py/check_maps.py; region renumbering needs no re-key.

## signatures
- `PY scripts/census/signatures.py {scan|propagate --name N --addr A|check|bulk-neutral [--dry-run]} [--rom P] [--registry P] [--fixture [--fixture-alter K]]`
- `scan`: function bodies (entry .. next entry or region end) + region bodies over verified code rows.
- Layers: exact (sha1 of bytes) / normalised / sequence; group id `f|r` + `E|N|S` + 10 hex.
- Output: ignored `.run/signatures/{functions,groups}.tsv`, `summary.txt`.
- Registry `config/names/routines.tsv` (header `addr name kind group layer sighash region evidence`); written only by `propagate` / `bulk-neutral`, never hand-edited; names lower_snake (`NAME_RE` refuses upper case: `fn_<addr6>` in lower-case hex).
- Fail-closed: per member, layer hash recomputed from `--rom` + `db.py listing` self-check `match` + `make build` OK; any member failing refuses the whole group, registry unchanged; a group already in the registry refuses.
- Propagated members named `<name>` (seed) and `<name>_<ADDR6>`.
- `bulk-neutral`: one exact-layer row `fn_<addr6 lower>` (evidence `T8 bulk neutral entry`) per unregistered function body whose functions.tsv name is the Ghidra default `fn_<ADDR6>`; other names counted `skip-named`; an unregistered default member of an N-group with a non-neutral member becomes `<seed>_<addr6 lower>`.
- Gated once per batch: exact hash from `--rom`, one `db.py listing` of all target regions (`match`), `make build` with the candidate registry in place; any failure or clash (registry, ram.tsv, region ids, NAME_RE/mnemonic) refuses the batch, registry restored byte-identical. Prints `bulk-neutral: <n> named, skip-named <k>` or `refused: <gate> <ids>`; follow with `db.py mirror`.
- `check` = health pair `signatures`; prints `<n> ok`; exit 1 on registry drift.
- Gates 2+3 run on a scratch copy of the names dir (`make build SRC=<scratch> NAMES=<scratch names>`); `config/names/routines.tsv` is written only after every gate passes. Controls: a planted bad candidate is refused at gate 2; `propagate --plant-gate3` corrupts one scratch src after gate 2 and must be refused at gate 3 (`make build exit 2`); `git diff --quiet config/names` holds throughout.
- Test refusal on a header-only registry copy (`--registry`).

## names
- Tracked: `config/names/ram.tsv` (`addr size name kind struct evidence`, kind `ram|io|rom`; `rom` = addr < ROM size: data table or non-function code label), `config/names/structs.tsv` (`struct field offset size evidence`), plus kind=code rows of `routines.tsv`; `hw.tsv` and `consts.tsv` (section constants).
- Names dir: `make ... NAMES=<dir>` (default `config/names`; feeds `split.py --names` and `db.py listing --names`, stamped in `asm/.names`, so switching it re-lists and re-splits); `ledger.py` reads env `MMTT96_NAMES` (same default).
- `split.py` generates `asm/hw.inc` (hw.tsv equates + `function` forms), `asm/ram.inc` (ram/io rows + struct fields) and `asm/rom.inc` (rom rows + code names), all ignored, never tracked, included in that order after the AS header (plan 1.9 T3; replaced `names.inc`); ram rows >= $FF0000 as sign-extended 32-bit `$FF<addr6>` e.g. `$FFFFC220`, io/rom/code rows 24-bit; code-name asserts at the end of `main.asm`; the `db.py listing` self-check wrapper includes the same three.
- `split.py` refuses reserved names (68000 mnemonics) and duplicate names (across the three includes) or addresses.
- A routines.tsv code name equal to a region id (e.g. `imp_decrunch`): no equ in rom.inc (the region label defines it; an equ double-defines); its `main.asm` assert compares to the absolute address (`if <name> <> $<addr6>`), so a wrong-address row fails the build; `db.py listing` (own rom.inc keeps the equ) renders call targets with the region name.
- Rendering: `PY scripts/ghidra/db.py listing ... [--names DIR|--no-names]`.
  - abs.w operand -> name only if its sign-extended word address equals the name's address.
  - abs.l -> name only if high byte $FF and low 24 bits >= $FF0000 (RAM, looks up the low 24 bits), or high byte 0 and value < $FF0000 (io/rom/code); high byte 0 with value >= $FF0000 stays raw.
  - Struct-typed ram row: exact field offset -> `<base>+<struct>_<field>`; else `<base>+<struct>_<field>+<d>` (d decimal, no `$`) with field = greatest field offset <= off, d a multiple of the field size and d < the struct's smallest gap between consecutive field offsets (e.g. `ram_slottab+slot_f00+2`); else raw.
  - Otherwise raw hex (AS would emit a longer form for an abs.w name that cannot be sign-extended, e.g. VDP control port).
  - Immediates stay raw except at control ports (hw.tsv) and consts.tsv rows (section constants); struct field at +0 renders as the bare base name; routine names render only for targets in other regions; a cross-region pc-relative/branch target with no code name falls back to an in-ROM ram.tsv name (kind `rom`).
- After editing `config/names`: `db.py mirror` -> `db.py roundtrip` -> `PY scripts/health/pairs.py names` (pair fails while unmirrored > 0).
- Naming convention (as practised): RAM `ram_` prefix; I/O by device (`io_`, `vdp_`, `z80_`); structs lower case, offset fields `f<OFF>`/`w<OFF>`; routines lower_snake; never a bare mnemonic word; neutral placeholder `<prefix>_<ADDR>` (e.g. `ram_FFD0E6`).
- Evidence rule: every row has an `evidence` pointer (claim id, oracle datapoint file, region id or task log); a meaning-bearing name needs >= 3 value datapoints, else a neutral or structural placeholder (a write census shows a field is written, never what it means).

## constants
- Plan 1.9 T3. `config/names/hw.tsv` (`name value kind evidence`): published Mega Drive hardware constants (evidence `published-doc: <source>`, e.g. the VDP register map of the Genesis Software Manual / MacDonald genvdp.txt, plus the observed use, e.g. `writers.tsv vdp_reg_01 3/3`). Kinds: `vdp_reg` (register-set word $8000|reg<<8, regs 00-17), `field:<vdp_reg name>` (data-byte bits), `vdp_cd` (access code CD5-0), `form` (value `args:expr` -> AS `function`: `vdp_cmd_hi`/`vdp_cmd_lo(adr,cd)`, the two access-command words), `value:<class>` (exact), `bit:<class>` (bits), `bitno:<class>` (btst-family bit numbers), `basereg` (a register that holds a port base for the whole game, `basereg_a6` = vdp_data; evidence `rom:`), `fact` (no equ; `vdp_no_scaling`: the VDP has no scale/zoom/rotation hardware).
- Classes (db.py `HW_PORTS`): `vdp_ctrl` C00004/C00006, `z80_busreq` A11100, `z80_reset` A11200, `io_data` A10003/5/7, `io_ctrl` A10009/B/D. Out of scope (raw): vdp_data, PSG C00011, J-Cart, Z80 RAM mailbox.
- Rendering (`db.py hw_operands`): an immediate stored or bit-tested at a class port (absolute, or (An)/d16(An) with An a port base: basereg, or a lea/movea.l of a port address moved by addq/subq/adda/suba/lea, passed into in-region callees, dropped at rts/rte/jmp/bra and on other writes) -> `#<expr>`: exact value row; register-set word -> `vdp_reg_X|<fields>|$<rest>`; access-command word pair (hi then lo, both immediate) -> `vdp_cmd_hi/lo($adr,<cd name>)`, a lone word -> numeric adr/cd; else greedy bit rows + `|$<rest>`; else raw.
- `config/names/consts.tsv` (`addr opnd expr evidence`; opnd 1-based): a game constant `#<expr>` at an immediate (incl. moveq/addq/subq); empty until a constant has >= 3 datapoints or a confirmed mechanics claim. The value is proven by the listing self-check (a wrong expr is a `mismatch`, tested at 1.9 T3).
- `PY scripts/census/constants.py check [--names DIR] [--plant]`: renders every code region from `.run/ghidra/listing/<id>.tsv` (needs `make build`, else exit 2); prints `RAW $ADDR <class>` / `BASE $ADDR <reg>` (a basereg write other than lea of the base, movem from (SP)+ or region init) / `CONSTS ...` / `HW <name>: <why>` (unknown kind, evidence class, register form, repeated value in a kind), then `constants: hw <sym>/<n> symbolic, game <k>` (1.9 T3: 100/100, 0); exit 1 on any line. `--plant`: same check on a scratch names copy with `z80_bus_request` $100 -> $200; exit 0 iff it leaves raw candidates.

## encodings
- `PY scripts/census/encodings.py [--write-map] [--plant]`
- Classifies every instruction of every verified code region (boundaries.py sweep, reads `.run/boundaries/ghidra/`) into forms `<mn>[.<sz>]:<modes>` (394 forms at phase 1.6 close).
- Output: ignored `.run/encodings/{forms.tsv,summary.txt}`; prints `encmap: forms m/n mapped`.

- Exit 1 on an unmapped/stale form, a sweep-count mismatch or a missing listing; `--plant` must exit 1.
- Health hard-fail rung `encmap`; new forms from newly verified regions need `--write-map`.

## ledger
- `PY scripts/census/ledger.py {write|check|report} [--src DIR] [--skip-listing] [--ledger PATH]`
- Tracked `config/campaign/ledger.tsv`: one row per `kind code` region + one per inferred non-code region (header `id kind status insns bytes raw_abs named_ops labels embedded_bytes comments entries named_entries closeness class blocker route evidence system system_basis`).
- `write`: `db.py listing <all code ids> --out .run/ledger/src` (scratch, never `asm/src`), timed; wall secs + per-region self-check -> `.run/ledger/meta.json`; `--skip-listing` reuses both. Inferred code rows get the listing columns like verified ones. Inferred non-code rows: kind = region kind, insns + listing columns `-`, class `inferred`, blocker `inferred region; no verdict`.
- Classes: verified `embedded-data` > `unowned-head` > `srcform-ok`; inferred code `lone-return` (row in `boundary_exceptions.tsv`) else `inferred`; inferred non-code `inferred`.
- closeness = nameable raw addresses + unnamed entries + embedded runs.
- Nameable excludes every `$hex` inside an operand that starts with `#` (T34: `#vdp_reg_autoinc|$2`, `#vdp_cmd_hi($C000,...)`; `ledger.in_imm`, also used by `sweep.py`).
- Hand-set rows: evidence not `auto` keeps class/blocker/route/evidence across `write`.
- Route vocabulary (`ROUTES`, T33): `unattended developer-review promote re-kind keep-inferred`; the condition (e.g. `on a verified caller or an execution`) lives in the blocker; `check` exits 1 on `ledger: ROUTE n rows` (a code or hand-set row with a route outside it).
- Route (auto code rows): `unattended` if insns < 50 else `developer-review`; empty computed blocker (closeness 0) -> `comments and meaning names pending`.
- `check`: `ledger: code regions r/n undecoded u; inferred i without-verdict w` (r/n code rows; i inferred rows any kind; w those with evidence `auto`); exit 1 if u > 0, w > 0, stale (id/kind/status/bytes vs regions code + inferred non-code rows) or `ledger: INCOMPLETE n rows` (empty class/closeness/blocker, or code row with empty route). `--ledger PATH` checks another TSV (negative controls). undecoded = code ids absent from `asm/.srclist` + `auto` inferred/lone-return code rows.
- `check --complete` (plan 1.9 T4): also `ledger: complete c/n code rows; no-plate p; entries pending e/E; operands raw r, neutral names pending o/O` from `asm/src` (needs `make build`, exit 2 without it); exit 1 unless every code row has a plate comment (`comments.tsv` type `plate` in the region), every function entry (`.run/signatures/functions.tsv`) and named operand is meaning-named or its evidence carries `unresolved:`, and no raw nameable operand remains. Neutral = `_<hex6>` suffix or evidence saying neutral/structural. Baseline 1.9 T4: 0/252, no-plate 242, entries 689/703, raw 525, neutral 2124/2143. Plain `check` unchanged.
- `report`: strata (insns <50, 50-300, >300), embedded bytes/runs, wall time, raw_abs/nameable, class counts, top-2 executed candidates per stratum (group member, coverage, insns asc, id); then (1.9 T11) `systems` rows/insns per system, `batches n (open o)` with batches/insns/waves per batch system, one line per batch.
- Columns `system system_basis` (1.9 T11, last two): set by `systems.py map`, kept by `write` for every row (new code rows get an empty `system`). `check` also exits 1 on `ledger: NO-SYSTEM n code rows` and on `ledger: BATCHES ...` (a code row not in exactly one batch of `config/campaign/batches.tsv`, a batch region that is no code row, or the file missing). Control 1.9 T11: blank one `system` in a scratch copy, `check --ledger <copy>` -> NO-SYSTEM 1, exit 1.

## systems
- `PY scripts/census/systems.py {map|show} [--src DIR] [--force] [--verbose]` (plan 1.9 T11): every code row -> a system, and the wave queue. Needs the listing of `ledger.py write` (`--src`, default `.run/ledger/src`) and `.run/ghidra/seed/refs.tsv`.
- Systems: the plan's groups `view-and-scrolling rules course collisions vehicle-handling data`, else `rest:<family>` (`menus sound-driver music-effects attract input initialisation decompression other`). No 3D-style terms in names (developer terminology rule).
- Basis (`system_basis`): `located: <sections>` (named in a `Located:` line of `docs/mechanics.md`: region ids, `code_A to code_B` ranges, fn_/group names via `routines.tsv`; several groups -> most sections, tie earlier group, or the `OVERRIDE` table in the script with its reason); `proximity<k>: ...` (votes: calls a located non-hub, non-sound-cue region 2; callee of at most 3 callers all in one group 1 each; located RAM word 1, or 0.5 above 8 users; located table read 1; best >= 2 and >= 2x runner-up; 2 passes); `rest: <why>` (z80_/imp_/init identity, Z80 RAM operands, mode word `ram_FFE69A`, pad ports, called only from one rest family, attract-only or boot-only coverage, else other).
- `config/campaign/batches.tsv` `batch order system wave route kind regions insns status`: whole regions; small rows (insns < 50) -> `comments-only` batches (T24, balanced); each group in caller-family order (call-graph components, largest first) packed to about 1,500 insns (a region of 1,500+ alone; up to 1.15x); the rest as one stream in family order (a batch spanning families has system `rest:a+b`). Queue = wave order: group waves T12..T22 take their group's first 2 batches, T24 comments-only, R waves T25..T31 two each (mechanics overflow first), beyond `excess`. Route developer-review if any region is. The waves set `status` (open -> done); `map` refuses to rewrite a file with a non-open batch unless `--force`.
- `show` prints counts per system/basis and batches per system (`--verbose`: every region and batch, ids and counts only).

## sweep
- `PY scripts/census/sweep.py operands [--layer ram|io|rom] [--dry-run]` (T8 mechanical naming sweep).
- Lists every `kind code` region (`db.py listing --out .run/sweep/src`, scratch), collects raw `$hex` operands that `ledger.py nameable()` counts (ledger `parse()` tokenizer), appends neutral `config/names/ram.tsv` rows (evidence `T8 sweep neutral (operand census)`), file re-sorted by address; rerun is a no-op.
- ram `$FF0000-$FFFFFF` (abs.w sign-extended) -> `ram_<ADDR6>`; io: `$A00000-$A0FFFF` `z80_`, `$C00000-$C0001F` `vdp_`, else `io_`; rom (< ROM size) -> `dat_<ADDR6>` in a non-code region, `lbl_<ADDR6>` in a code region.
- size = widest access width seen (b 1, w 2, l 4; unsized 1). Skips: already named, interior of a struct-typed row, name collision; rom also signature entries and code region starts. Ghidra-only function entries (interior call targets) are swept since T34.c2 (labels apply after analysis, roundtrip identical); `.run/ghidra/seed/functions.tsv` no longer read.
- Prints `sweep: <layer> new n skip-<reason> n`. After a write: `db.py mirror` -> `roundtrip` -> `pairs.py names`.

## commentcheck
- `PY scripts/census/commentcheck.py [--table PATH] [--src DIR] [--self-test] [--doc PATH]` (plan 1.7 T8; wave 1 had 23/42 draft comments wrong).
- Checks each comment of `config/ghidra/comments.tsv` against tracked tables + the `asm/src` listing (needs `make build`; exit 2 without it): comment address in a region and, in code, an instruction start; every `a_b` identifier a name (ram/routines/structs), region id or maps claim id (a `ram_<hex6>` range end may lie inside a tracked RAM span), `_<hex6>` suffix = its table address; 6-digit ROM hex inside a region (code: instruction start unless a range end) or work RAM; ranges ascending; `signature group G[: list]` membership, `one of N ... (signature group G` = group size; `(group NAME` family; `N such ... at list`; `executed in [all] N [qual] coverage run(s)` vs `config/oracle/coverage.tsv`.
- Prints `FAIL <addr> <check>: <why>` per failed claim and `commentcheck: comments n claims c failed f`; exit 1 if f > 0.
- `--self-test`: `scripts/census/fixtures/commentcheck_good.tsv` (real rows) must pass and every row of `commentcheck_bad.tsv` (planted wrong count, member list, coverage, family, name, address, range, group) must fail. Standalone (no asm/src, ROM or Ghidra; CI no-dump job): instruction starts come from `fixtures/commentcheck_starts.txt` (addresses only, the fixture addresses that are starts); regenerate it from a built tree when a fixture row changes.
- Not checked: free counts and sizes (`64 zero words`, `16-byte table`), behaviour wording; those stay developer-review.
- `--doc PATH` (plan 1.9 T4): claim lines of a mechanics doc (`docs/mechanics.md`), no listing needed. Every `- ` bullet under a `## `/`### ` heading (outside code fences) ends with `[confirmed: p, ...]`, `[hypothesis: p, ...]` or bare `[hypothesis]`. Pointers: path (has `/`, optional `:line`) exists; `P<nnn>` in `config/oracle/probes.tsv`; `<tag>_<YYYYMMDD>T<HHMMSS>` (or `a+b`) in a `run`/`runs` column of `config/oracle/*.tsv`; else region id or ram/routine/hw name, struct, `struct.field`. `confirmed` needs >= 3 distinct run ids or one `controlled` probe. Prints `FAIL <path>:<line> <kind>: <why>` (kinds marker name run probe path confirmed) and `commentcheck: doc <path> bullets b pointers p failed f`; exit 1 on a failure or 0 bullets. `--self-test` also runs `fixtures/commentcheck_doc_{good,bad}.md` (synthetic): good passes, every bad bullet fails, all 6 kinds caught.

## contract
- `bash scripts/contract.sh --dump PATH [--asl-zip PATH] [--dir PATH]` (plan 1.8 T6; env `MMTT96_DUMP`, `MMTT96_ASL_ZIP`, `MMTT96_CONTRACT_DIR`; README env `PY`, `GHIDRA_INSTALL_DIR`, make on `PATH`).
- Clones committed HEAD with `-c core.autocrlf=true` into a dot-free scratch dir (default `<repo parent>/_contract/<ts>`; a dotted path or an existing dir is refused; never deleted), asserts `git ls-files --eol` has 0 `w/crlf`, then README steps 3-5 cold: `bootstrap.sh`, `make build`, `make health`, plus `ledger.py check`; times each.

- Run detached (`tools/run.sh --bg contract -- ...` + `--wait contract --max 280`): cold run about 2.5 min. Live oracles (`make health-live`) are excluded. Tracked record: `docs/verification.md`.
