# Security

This project holds no secrets: no keys, tokens or credentials are needed to build it or are stored in it.

## Reporting a concern

- Preferred: use GitHub private vulnerability reporting ("Report a vulnerability" on this repository's Security tab).
- Otherwise: open an issue that describes the concern without sensitive details; a maintainer will follow up.

Never attach a ROM, a dump, a disassembly listing, a memory image or a save state to a report, an issue or a pull
request.
